# FX Pro Terminal

**FX Pro Terminal** 是一個可安裝的繁體中文匯率換算 PWA。它以港幣（HKD）作為內部換算基準，提供多幣別同步換算、內建四則運算計算機、可自訂貨幣清單與離線使用支援。

> 匯率僅供參考。實際銀行、發卡機構或換匯商的成交匯率與費用可能不同。

## 功能

| 功能 | 說明 |
|---|---|
| 多幣別換算 | 預設同時顯示 20 種常用貨幣，並以任一貨幣輸入值重新計算。 |
| 彩色幣別卡片 | 使用指定 [RGB 顏色列表](COLOR_PALETTE.md) 的固定不重複淡色配色、國旗與貨幣縮寫，讓長清單也能快速掃讀。 |
| 內建計算機 | 透過受限的四則運算解析器計算金額，不執行動態 JavaScript。 |
| 清單管理 | 可新增、刪除非預設貨幣，並在編輯模式拖曳調整排序。 |
| 熱門貨幣釘選 | 在編輯模式以星號釘選常用貨幣；已釘選項目會固定優先顯示，且偏好與排序會保存在瀏覽器中。 |
| 資料來源切換 | 可於 Currency API 與 Open ER API 之間切換；選擇會保存在瀏覽器中。 |
| 深色／淺色模式 | 頂部工具列提供一鍵圖示切換；偏好會保存在瀏覽器中，並在重新載入後持續套用。 |
| 卡片密度與配色 | 透過頂部圖示設定面板可切換「緊湊／舒適」密度，以及「鮮明／柔和／極簡」卡片配色；選擇會立即套用並保存在瀏覽器中。 |
| 快速啟動與離線備援 | 依匯率來源保存最後一次驗證成功的全部匯率；15 分鐘內會直接呈現快取卡片，之後於背景同步。網路暫時失敗時會清楚標示快取狀態，超過 48 小時則顯示過期警示。 |
| 可安裝 PWA | 包含 Web App Manifest、安裝圖示與 Service Worker，首次成功載入後可離線開啟應用程式介面。 |

## 資料來源

本專案可使用下列公開資料來源：

| 名稱 | 端點 | 用途 |
|---|---|---|
| Currency API | `@fawazahmed0/currency-api` 的 jsDelivr CDN | 提供以 USD 為基準的貨幣匯率資料。 |
| Open ER API | `https://open.er-api.com/v6/latest/USD` | 提供以 USD 為基準的貨幣匯率資料。 |

應用程式會驗證回應狀態、資料格式與 HKD 匯率有效性，再將資料轉換為「1 HKD 可兌換的外幣金額」。每個資料來源均有獨立的本機快取，包含來源資料時間與本機寫入時間；15 分鐘內的快取會直接渲染所有貨幣卡片而不等待匯率網路請求，並在期限後以背景同步更新。資料請求會在 10 秒後逾時；若請求失敗，系統會保留相同來源的快取內容；快取超過 48 小時時，會以警示狀態提示使用者。

## 本機使用

此專案不需要建置工具。為讓 Service Worker 與 PWA 功能正常運作，請使用本機 HTTP 伺服器，而非直接以 `file://` 開啟 HTML。

```bash
python3 -m http.server 8080
```

然後在瀏覽器開啟 `http://localhost:8080`。在支援安裝的瀏覽器中，當安裝條件符合時，控制列會出現「安裝」按鈕。

## 專案結構

```text
.
├── index.html              # 介面與樣式
├── app.js                  # 匯率、計算機、快取與拖曳排序邏輯
├── manifest.webmanifest    # PWA 中繼資料
├── service-worker.js       # App Shell 離線快取策略
└── icons/                  # PWA 與遮罩安全圖示
```

## 隱私

使用者選擇的貨幣、資料來源、明暗主題、卡片密度與卡片配色偏好，以及最後一次成功的匯率資料，只會透過瀏覽器的 `localStorage` 保存在使用者裝置上。本專案不設後端，亦不會自行收集帳號或個人資料。
